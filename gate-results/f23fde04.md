## SILENT (critical)

Six of the seven share one shape. A **typed** composite slot holds `undefined`, from an out-of-range `T[]` read or a missing `Map`/array entry. When that value reaches a **dynamic consumer** (spread, `Array.isArray`, `util.inspect`, object spread, `fs.existsSync`), the wasm module **dereferences a null pointer**. The trap stacks run through `%view.N.len` ← `%w.dyn.fnThunk` ← `%w.dyn.viewCall0` ← `%w.dyn.viewLen` ← `%w.dyn.viewArrSnap` ← `%w.dyn.arrOf`, or through `%w.dyn.viewObjSnap` ← `%w.dyn.objOf` ← `%w.dyn.spreadSource`. These are U1a's shared-view paths reading a null view. The process exits 1 with no `tsinter:` diagnostic and no `[SC…]` code. Node's output is in the rows, and the program's stdout stops partway.
