## SILENT (critical)

### U1-RES-01 (wasm lane), intermittent

`tests/harness/wasm-differential.test.ts > INC-28 U1 child_process rows > U1-RES-01 every spawnSync result field per outcome: exit 0, exit 3, signal, spawn failure, timeout, trapped timeout (status AND error)`

Program (from the row):
```ts
import { spawnSync } from "node:child_process";

const show = (label: string, file: string, args: string[], timeout: number, outputs: boolean): void => {
  const r = spawnSync(file, args, { encoding: "utf8", timeout: timeout });
  const code = (r.error as NodeJS.ErrnoException | undefined)?.code;
  const io = outputs ? ` out=${JSON.stringify(r.stdout)} err=${JSON.stringify(r.stderr)}` : "";
  console.log(label, `status=${r.status}`, `signal=${r.signal}`, `error=${r.error === undefined ? "undefined" : r.error.message}`, `code=${code}` + io);
};
show("exit0:", "/bin/sh", ["-c", "printf a; printf b 1>&2"], 0, true);
show("exit3:", "/bin/sh", ["-c", "printf a; exit 3"], 0, true);
show("signal:", "/bin/sh", ["-c", "printf a; kill -TERM $$"], 0, true);
show("spawnfail:", "definitely-not-a-binary-xyz", [], 0, false);
show("timeout:", "/bin/sh", ["-c", "printf a; sleep 5"], 300, true);
show("trapped:", "/bin/sh", ["-c", "trap 'printf t; exit 4' TERM; printf a; sleep 5 & wait"], 300, true);
show("trapped-quiet:", "/bin/sh", ["-c", "trap 'exit 4' TERM; printf a; sleep 5 & wait"], 300, true);
```

Node's expected output, compared with what the wasm lane printed in stage f:
```diff
  exit0: status=0 signal=null error=undefined code=undefined out="a" err="b"
  exit3: status=3 signal=null error=undefined code=undefined out="a" err=""
  signal: status=null signal=SIGTERM error=undefined code=undefined out="a" err=""
  spawnfail: status=null signal=null error=spawnSync definitely-not-a-binary-xyz ENOENT code=ENOENT
  timeout: status=null signal=SIGTERM error=spawnSync /bin/sh ETIMEDOUT code=ETIMEDOUT out="a" err=""
- trapped: status=null signal=SIGPIPE error=spawnSync /bin/sh ETIMEDOUT code=ETIMEDOUT out="a" err=""
+ trapped: status=4 signal=null error=spawnSync /bin/sh ETIMEDOUT code=ETIMEDOUT out="a" err=""
  trapped-quiet: status=4 signal=null error=spawnSync /bin/sh ETIMEDOUT code=ETIMEDOUT out="a" err=""
```
- stderr: none. There is no `tsinter:` line and no `[SC…]` code.
- Exit code: the row failed on stdout, so the wasm lane's exit code isn't in the log. The program returns normally, and the row checks stdout first.
- What it means: in Node, the timed-out child's `printf t` in its TERM trap writes into a pipe that is already closed, so the child dies of SIGPIPE. Node 24.18.1 gave SIGPIPE in 10 of 10 standalone runs. In the failing wasm-lane run, the pipe was still open when the trap ran, so `printf t` succeeded and the child exited 4. This looks like an ordering race in the lane's spawnSync timeout path: the child is signalled before its stdout/stderr pipes are closed, where Node closes them first. Note that `out="a"` matches Node, so the late `t` was not captured.
- How often: it failed in stage f, under the full parallel suite. It passed in stage c, passed once alone, and passed 6 of 6 alone with 4 CPU-burner processes running. On the wasm-native lane, its host-row copy (`U1-RES-01 (#11)`) passed in both d and f.
- This is new compared with f23fde04's gate, where U1-RES-01 was not reported. It is not on the known list.
